# Pixel artwork refinement

The existing pixel-rhythm.svg is reused through prominent, medium, and subtle pixel-surface variants. No animation, new artwork, or repeated tiling was introduced.

Prominent surfaces frame Home 1’s performance feature and closing enrollment invitation. Dark copy panels preserve contrast against the stronger mosaic. Medium treatments accent the Class Finder heading, Courses introduction, and About introduction. The Instructors introduction has a small corner motif. The artwork stays outside photographs, inputs, result listings, and dashboard records.

Full-page Brave captures covered all five affected routes at 390, 768, 1024, and 1440 px in light LTR and dark RTL, for 40 combinations. Visual review checked text, actions, photo visibility, and the balance of artwork across each page. The first introduction treatments were strengthened and feathered after review. The final set passed overflow and placement checks. Existing form and navigation handlers were preserved.
